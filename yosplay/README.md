# YOS Play

Tercera aplicación Android independiente del ecosistema YOS, con su propio package `com.yos.streaming.yosplay`.

## Incluye

- Inicio de sesión Xtream Codes (servidor, usuario y contraseña o enlace `get.php`).
- Catálogos de TV en vivo, películas y series, categorías y búsqueda.
- Favoritos guardados por cuenta en el dispositivo y guía Ahora/Sigue cuando el proveedor exponga EPG.
- Reproducción Android con Media3 y controles compatibles con TV Box.
- Credenciales recordadas protegidas con Android Keystore.
- Marca YOS y artefacto APK separado de YOS Streaming y YOS Xtream.

La app requiere una API compatible con Xtream del proveedor y acceso autorizado a sus contenidos. No incluye listas ni credenciales preconfiguradas.

## Descargar

GitHub Actions genera el artefacto `YOS-PLAY-APK` al compilar el repositorio.
